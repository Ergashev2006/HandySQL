# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-02-10

### Added
- SQLite, MySQL, PostgreSQL support
- SQLBuilder pattern
- CRUD operations (Create, Read, Update, Delete)
- WHERE conditions (=, IN, BETWEEN, LIKE, NULL)
- JOIN operations (INNER, LEFT, RIGHT)
- GROUP BY and HAVING
- ORDER BY, LIMIT, OFFSET
- DISTINCT
- Transactions
- Context manager support
- Statistics functions (COUNT, SUM, AVG, MIN, MAX)
- Pagination
- JSON export/import
- Table management
- Foreign key support
- Full error handling
- Logging

### Documentation
- README.md
- Examples (examples.py)
- Unit tests (tests.py)
- Setup file

## [0.1.0] - Beta

### Added
- Initial release
- SQLite support
- Basic CRUD operations
